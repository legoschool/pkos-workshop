# PKOS 도구 모음 · 기록장 · 변환기 · 사이트 만들기

흩어진 수업 자료와 생각을 모으고, 쌓고, 나누는 세 도구의 사용법을 한곳에 모은 실습 교재입니다.

**사이트: https://legoschool.github.io/pkos-workshop/**

| 도구 | 하는 일 | 바로 쓰기 | 저장소 |
|---|---|---|---|
| 기록장 · PKOS 나의지식서재 | 메모·문서·사진에 생각을 더해 잇는 개인 서재. 로그인 없이 브라우저에 저장 | [체험 서재](https://legoschool.github.io/pkos-library/?demo=1) · [사용 설명서](https://legoschool.github.io/pkos-library/manual/) | [legoschool/pkos-library](https://github.com/legoschool/pkos-library) |
| 변환기 · PKOS 자료변환기 | 블로그·한글·워드·PPT·엑셀·구글 문서를 마크다운으로 | [코랩](https://colab.research.google.com/github/legoschool/pkos-fileconverter/blob/main/PKOS_%EB%B3%80%ED%99%98%EA%B8%B0.ipynb) · [실습 교재](https://legoschool.github.io/pkos-textbook/) | [legoschool/pkos-fileconverter](https://github.com/legoschool/pkos-fileconverter) |
| 사이트 만들기 · 웹 게시본 제작기 | 폴더의 글·사진과 `_메모.txt` 한 장으로 웹 페이지 만들기 | [제작기](https://legoschool.github.io/pkos-publisher/%EC%A0%9C%EC%9E%91%EA%B8%B0.html) | [legoschool/pkos-publisher](https://github.com/legoschool/pkos-publisher) |

사이트는 13개 학습 블록(기록장 5 · 변환기 3 · 사이트 만들기 3 · 가져가기 · 만든 과정), QR과 링크 모음, 진행 순서와 막히는 곳으로 되어 있습니다. 블록마다 실제 화면 사진과 확인할 행동이 있고, 체크와 메모는 보는 사람의 브라우저에만 저장됩니다.

## 들어 있는 것

| 파일 | 내용 |
|---|---|
| `index.html` | 사이트 전체 (블록은 `#b01`~`#b13`, QR은 `#qr`, 진행 안내는 `#review`) |
| `assets/` | 모양(`site.css`)과 동작(`site.js`) |
| `img/` | 화면 사진 35장 (WebP) |
| `qr/` | 세 도구와 이 사이트의 QR 코드 (SVG) |
| `files/maker-sample.zip` | 제작기 실습용 예시 폴더 「우리반-텃밭-기록」 (지어낸 내용) |
